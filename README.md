(16:9, français) avec notes orateur, couvrant les 4 points demandés :

1. Business Understanding (contexte, problématique, décideurs)

3. Méthodologie de travail (préparation des données, BI, ML)
4. Modèle du Data Warehouse (faits, dimensions, mesures)

Générée par `build_presentation.py` (branche `main`) : les chiffres sont recalculés depuis le dataset.
