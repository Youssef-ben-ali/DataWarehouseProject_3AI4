# Présentation – première validation (modèle révisé, version B)

[`Presentation_Validation1_HealthRetailers.pptx`](Presentation_Validation1_HealthRetailers.pptx) : 19 diapositives
(16:9, français) avec notes orateur, couvrant les 4 points demandés :

1. Business Understanding (contexte, données réelles et prolongation synthétique, problématique, décideurs)
2. Objectifs du projet (objectif global → sous-objectifs métier → objectifs BI / ML)
3. Méthodologie de travail (préparation des données, BI, ML)
4. Modèle du Data Warehouse – version B : 3 tables de faits, 4 dimensions, mesures Power BI

Générée par `build_presentation.py` (branche `main`) : les chiffres sont recalculés depuis le dataset (période réelle
pour les chiffres de contexte et le premier signal ML, 2 ans pour le modèle).
Attention : relancer le script écrase les modifications faites à la main dans PowerPoint.
